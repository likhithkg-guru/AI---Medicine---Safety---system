# 💊 MedSafe AI

🚀 AI Powered Fake Medicine Detection System

MedSafe AI is a smart healthcare web application that helps users:

✔ Detect fake medicines  
✔ Scan medicine strips using OCR  
✔ Check expiry dates  
✔ Search medicine information  
✔ Register complaints against suspicious medical shops  

---

## 🧠 Tech Stack

- Python
- Flask
- HTML/CSS
- SQLite
- Tesseract OCR

---

## ⚡ Features

🔍 AI Medicine Scanner  
💊 Medicine Information Portal  
🚨 Complaint Registration System  
🎨 Futuristic UI
